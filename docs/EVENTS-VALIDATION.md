# 事件默认总览验收

事件 Tab 打开时默认总览，上海今日起查询全部未过事件，不设上限。全局交易日期仅继续驱动其他归档内容；事件日历使用 Tab 内独立事件日期，显式选日后可一键回到总览。近 7 天已过折叠区维持原有行为。API、协议、鉴权与数据库不变。

- lint、完整 38/38 测试通过；模型测试覆盖无上限升序分组、日期差、单日过滤、最近提示及过去 7 天。
- 浏览器使用系统 Chrome，390×844、固定上海今日与虚构 09999.HK 数据。测试先加载总览页面（全局日期=今天），再点击事件 Tab，未操作日期即断言 +3 天事件和「还有 3 天」徽标可见。
- 另验证直接进入带旧 events_view=day 的 URL 仍默认总览；全局日期输入、快捷日期按钮均不改变事件模式或范围；Tab 内显式选日可用，单日空态保留最近事件提示，一键回总览展示超过 30 天事件；无未过事件时总览保持空态。
- 浏览器断言无 pageerror，页面 scrollWidth 不超过 390px。旧 screenshots/events 图片为此前30天版本的历史记录，不作为本轮默认视图的验收证据。

复现：本机启动 `npm run dev`，另以 `PLAYWRIGHT_MODULE=<本机独立安装的Playwright模块入口> node tests/events-browser.mjs` 运行。浏览器脚本拦截所有 API，未查询或写入生产数据，不新增项目依赖。
